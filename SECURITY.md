# Security

ZM handles sign-ins and personal financial data, so security reports are
welcome.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/kspworks/zm-v2/security/advisories/new)
with the steps to reproduce and the impact you see.

This is a personal project maintained in spare time: there is no bug bounty
and no guaranteed response time, but every report is read.

## Scope

The code on `main`. Instances other people run are theirs to secure; the
[security notes in SELF-HOSTING.md](SELF-HOSTING.md#security-notes) list the
deployment pitfalls that are known.
